About RAPDAS

What is RAPDAS?

A free desktop tool that helps everyday users identify potentially dangerous Wi-Fi networks before connecting — no technical knowledge required.

When you're working at a mall café and your hotspot runs out, you might quickly connect to the nearest free Wi-Fi without thinking twice. This is exactly what attackers count on.

Rogue access points — fake Wi-Fi networks designed to look legitimate — can intercept your data, steal your credentials, and expose your work to malicious actors.

RAPDAS was built specifically for this scenario. It scans all nearby Wi-Fi networks and applies a rule-based system to flag networks that show signs of being potentially rogue, giving you the awareness to make safer choices.

Developed as a capstone research project studying public Wi-Fi networks in shopping malls across Las Piñas City.

🔍
Unknown OUI Vendor Detection
Identifies networks whose hardware vendor cannot be matched to any registered manufacturer — a common trait of improvised rogue setups.
📡
Duplicate SSID Detection
Flags networks that share the same name as another nearby network — a classic evil twin attack technique used to trick users into connecting.
📶
Weak Signal Strength Analysis
Detects networks with signal strength ≤50%, which may indicate a portable or limited hardware setup commonly used in rogue hotspots.
Setup Requirement

Install Npcap (Required)

RAPDAS needs Npcap to scan nearby Wi-Fi networks. Follow these steps before running the app.

01
Download Npcap
Click the button below or go to the official website to download the installer. Download the latest installer for Windows.
02
Run the Installer
Open the downloaded file (npcap-setup.exe) and proceed with the setup.
03
Enable Required Options
Make sure to check:
✔ WinPcap API-compatible Mode
✔ Support raw 802.11 traffic (if available)
04
Finish Installation
Click Install and wait for it to complete.

How to Use

Simple. Fast. No setup needed.

RAPDAS is designed for non-technical users. Just download, run, and scan.

01
Download the App
Click the Download button and save the RAPDAS .exe file to your computer. MAKE SURE NPCAP IS INSTALLED.
02
Run the File
Open the downloaded file. If Windows shows a security prompt, click "More Info" then "Run Anyway" — the app is safe to use.
03
Scan Your Area
Click the Scan button. RAPDAS will detect all nearby Wi-Fi networks and analyze them using its built-in detection rules.
04
Read the Results
Each network is labeled Safe, Suspicious, or Potentially Rogue with a reason. Avoid connecting to flagged networks.
